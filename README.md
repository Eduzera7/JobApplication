
# Job Application Simulator ☕

A simple Java console application developed as part of my BSc (Hons) Computing & IT studies at CCT College Dublin.

## About the Project

This project simulates a basic job application screening process using conditional statements.

The program asks the user for:
- Years of professional experience
- Visa type (1G or Study)

Based on the information provided, it displays a simulated application outcome.

**Note:** The visa-related conditions are fictional and intended only for programming practice.

## Technologies

- Java
- Scanner
- If/Else Statements
- Logical Operators
- String Comparison

## How to Run

1. Install the Java Development Kit (JDK).
2. Download `JobApplication.java`.
3. Open a terminal in the project folder.
4. Compile and run:

```bash
javac JobApplication.java
java JobApplication
```
